http://localhost:5000

Postman lets you test GET/POST/PUT/DELETE requests with headers, authorization, query parameters, JSON, and form-data.

1. Server Test
GET

Expected:

2. Authentication
Register Customer
POST
POST http://localhost:5000/api/auth/register

Body → raw → JSON

{
  "name": "Tharun Kumar",
  "email": "tharun@gmail.com",
  "password": "123456"
}

Expected:

{
  "message": "User registered successfully",
  "token": "...",
  "user": {
    "name": "Tharun Kumar",
    "email": "tharun@gmail.com",
    "role": "customer"
  }
}

Save the token.

Login
POST
POST http://localhost:5000/api/auth/login

Body:

{
  "email": "tharun@gmail.com",
  "password": "123456"
}

Expected:

{
  "message": "Login successful",
  "token": "...",
  "user": {
    "role": "customer"
  }
}

For protected endpoints, use Authorization → Bearer Token in Postman. Postman supports Bearer tokens specifically for JWT-style authentication.

5. Seller Product Creation

First you need a seller account.

Your current register endpoint creates customers by default, so create a seller directly in MongoDB for testing, or temporarily change the role in MongoDB:

{
  "role": "seller"
}

Then login with that seller account and get the seller JWT.

POST
POST http://localhost:5000/api/products

Authorization:

Bearer SELLER_TOKEN

Body → form-data

Key	Type	Value
name	Text	iPhone 15
description	Text	Apple smartphone
price	Text	60000
discountPrice	Text	55000
brand	Text	Apple
category	Text	CATEGORY_ID
stock	Text	20
sku	Text	IPHONE15-001
images	File	select image

You can add up to 5 images because your route uses:

upload.array("images", 5)

Postman supports form-data file uploads directly through the Body tab.

Expected result should contain:

"images": [
  {
    "url": "https://res.cloudinary.com/...",
    "publicId": "..."
  }
]

And your local folder should also contain the uploaded image:

backend/
└── uploads/
    └── products/
        └── generated-image-name.jpg

17. Stripe Payment

After creating an order with:

  "addressId": "ADDRESS_ID",
  "paymentMethod": "online"
}

Copy the ORDER_ID.

Then:

POST http://localhost:5000/api/payments/create-checkout-session

Body:

{
  "orderId": "ORDER_ID"
}

Expected:

{
  "message": "Checkout session created successfully",
  "sessionId": "...",
  "checkoutUrl": "https://checkout.stripe.com/..."
}

Open the checkoutUrl in your browser to test Stripe Checkout.

18. Stripe Webhook

This one is not tested like a normal JSON endpoint.

Your webhook is:

POST http://localhost:5000/api/payments/webhook

Stripe sends the webhook request.

Your code verifies the Stripe signature and then changes:

paymentStatus

from:

pending

to:

paid

Your webhook route must remain before express.json(), which you've already done.
